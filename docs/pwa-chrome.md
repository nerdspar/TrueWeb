# PWA chrome

This app follows the shared **PWA chrome spec** — status bar, safe areas, the iOS
top-blur fix, the `100dvh` shell, and the standardized tab bar (56px band · 24px
icon · 11px label · 4px gap · home-indicator cushion). It lives in the shared
playbook so all the apps stay in sync:

**→ https://github.com/nerdspar/app-playbook/blob/main/pwa-chrome.md**
